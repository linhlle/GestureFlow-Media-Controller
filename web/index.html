Control your Mac with your hands.

GestureFlow tracks one hand through your webcam and turns it into cursor movement, clicks, scrolling, volume, and keyboard shortcuts. Hand landmarks come from MediaPipe; a Random Forest classifies poses; a set of state machines decides when a movement was actually meant as a command.

Try the recognizer → Install the desktop app
What runs where. A web page runs in a browser sandbox. It cannot move your cursor, press your keyboard shortcuts, or change your system volume — no website can, and this one does not pretend otherwise. The demo on this site shows you the recognizer working on your own hand. Actually controlling the machine is the desktop app's job.

In your browser no install

  • Live hand tracking from your webcam
  • The same feature vector and the same trained forest the desktop app uses
  • The same click, scroll, and debounce state machines, ported to JS
  • A command builder that exports a config file
  • Video never leaves your machine — there is no server to send it to

On your Mac python app

  • Moves the real cursor and sends real clicks
  • Fires keyboard shortcuts and launches apps
  • Adjusts system volume through AppleScript
  • Loads the config you built on this site
  • Needs macOS Accessibility permission, which only you can grant

How it works

Four stages, each on its own thread.

StageWhat happens
Capture Grabs a camera frame and runs MediaPipe Hands to get 21 3D landmarks. Reconnects with backoff if the camera disappears.
Inference Converts landmarks to 63 features — wrist-relative, then scaled by the largest component, so the vector is the same wherever your hand is in frame and however far from the camera it sits. A 100-tree Random Forest classifies the pose.
Stabilisation A majority vote over a 10-frame window, plus finite state machines with hysteresis, decides whether a pose was deliberate. This is what separates a gesture from a hand that happened to pass through a shape.
Action A dedicated thread performs the OS call, so a slow keyboard shortcut never stalls the video. Cursor moves collapse to the newest position; clicks are never dropped.

Your own commands

Bindings live in a config file, not in the source.

Pick a gesture, choose an action, download the file, drop it in ~/.gestureflow/. The app validates it on load and picks up edits without a restart. Six action types are supported: keyboard shortcut, single keypress, media key, launch an app, run AppleScript, or run a command. 

version: 1
neutral_label: 0

gestures:
  - label: 1
    name: Spotlight
    action:
      type: hotkey
      keys: [command, space]

About performance numbers

This site does not quote a frame rate, a latency figure, an accuracy percentage, or a false-trigger rate, because those depend entirely on the camera, CPU, and lighting in front of them — a number measured on one machine would tell you nothing reliable about yours.

The repository ships the instrumentation to measure all of it on your own hardware: gestureflow bench reports per-stage timings and end-to-end latency as p50/p95/p99, and gestureflow false-triggers replays recorded footage to count actions that fired when you meant nothing. The guide shows how to run both.
