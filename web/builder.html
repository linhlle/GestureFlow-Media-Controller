GestureFlow Live demo Command builder Guide

Command builder

Bind each gesture to something your Mac should do, then download the config and drop it in ~/.gestureflow/.

This page writes a file; the desktop app runs it. Nothing here executes on your machine. The download is a plain text config that the Python app reads, re-validates, and acts on. If you would rather not download anything, start the app with gestureflow bridge and it can receive the config directly.

Action types

TypeWhat it doesExample
hotkeySends a key combination command + space
keypressPresses a single key escape
mediaPlay/pause, skip, volume, mute playpause
launchOpens an application Notes
applescriptRuns an AppleScript snippet tell application "Music" to pause
shellRuns a command as an argument list ["say", "hello"]

Shell commands are an argument list, not a command string, and the app runs them without a shell. Pipes, redirects, and && are treated as literal text rather than syntax — a config file cannot smuggle in a second command through quoting.

Configs are validated here and again by the app on load.
